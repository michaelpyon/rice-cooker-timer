# Rice Focus: Deferred Bets

`PERSONA.md`, `BRAND.md`, and `DESIGN.md` are the product source of truth. This file only holds work that was deliberately kept out of the 2026-07-22 release.

## Shipped in the AAA relaunch

- Responsive portrait and short-landscape cartridges. The 480x360 canvas scales uniformly instead of cropping on phones.
- Countdown begins on START and reconciles from an absolute wall-clock deadline after tab throttling or sleep.
- Remaining time in the document title and a persistent visual finish if audio is unavailable.
- START-gesture Web Audio activation, a shorter finish melody, reduced-motion handling, and a drawn favicon.
- Last-used duration persistence.
- Native share with clipboard fallback and stable rapid-tap feedback.
- Honest 1200x630 celebration card.
- 3-file Vercel allowlist that keeps product docs and local tool state private.

## Deliberately deferred

1. **Pause and resume**: useful when a cook needs intervention, but it complicates a single-purpose timer and is not required for the current stovetop job.
2. **Sound toggle**: the target user values an unmistakable finish. Add only if quiet-environment demand is observed, and keep the visual alert mandatory.
3. **Self-host Press Start 2P**: removes the final runtime request and font flash risk. If done, ship the OFL license and verify the public bundle stays minimal.
4. **More rice presets**: WILD or BLACK needs a sourced, honestly qualified default before appearing beside the friendly existing presets.

No item above blocks the current release.
